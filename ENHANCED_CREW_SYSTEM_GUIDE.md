# Enhanced Crew System - Complete Guide

## Overview

The enhanced crew system introduces **skill-based crew management** with **quality tiers**, **specializations**, and **captain level requirements**. Better crew want to join submarines commanded by experienced captains with good reputations.

---

## 🎖️ Crew Quality Tiers

### Quality Levels

| Quality | Captain Level | Base Skills | Description |
|---------|--------------|-------------|-------------|
| **RECRUIT** | Level 1+ | 40-60% | Green recruits, basic training |
| **TRAINED** | Level 3+ | 60-75% | Completed basic training |
| **EXPERIENCED** | Level 5+ | 75-85% | Combat-tested sailors |
| **VETERAN** | Level 8+ | 85-95% | Hardened veterans |
| **ACE** | Level 12+ | 95-100% | Elite specialists |
| **LEGENDARY** | Level 15+ | 100-120% | Legendary heroes (can exceed 100%) |

### Quality Effects

- **Higher quality = Better base skills** (40% → 120%)
- **Higher quality = Faster learning** (better XP gains)
- **Higher quality = Better stress resistance**
- **Higher quality = Higher recruitment cost**

## 🎯 Skill System

### Core Skills

1. **Engineering** - Repairs, maintenance, submarine systems
2. **Torpedoes** - Weapons operation, targeting, reload
3. **Sonar** - Detection, sensors, acoustic analysis
4. **Navigation** - Ship handling, positioning, routing
5. **Leadership** - Command, morale, coordination
6. **Medical** - Health, injuries, crew welfare
7. **Damage Control** - Emergency repairs, flooding
8. **General** - Basic submarine duties

### Skill Effectiveness Calculation

```
Effective Skill = Base Skill 
                + XP Bonus (up to +20%)
                + Specialization Bonus (up to +30%)
                + Personality Bonus (up to +5%)
                + Morale Modifier (±10%)
                + Health Modifier (up to +10%)
                - Stress Penalty (up to -40%)
                - Fatigue Penalty (up to -30%)
```

**Result:** 0% to 200% (legendary crew can exceed 100%)

### Experience Gains

- **Using skills:** 10 XP per action
- **Repairs:** 10 XP × severity
- **Combat:** 20 XP per successful hit
- **Detection:** 5 XP per contact identified
- **Level up:** Every 500 total XP

## 🏴 Recruitment System

### Captain Level & Reputation

**Captain Level** unlocks better crew quality:
- Level 1-2: Only Recruits available
- Level 3-4: Trained crew appear
- Level 5-7: Experienced crew available
- Level 8-11: Veterans join
- Level 12-14: Aces available
- Level 15+: Legendary crew may appear

**Reputation** affects recruitment pool:
- **Negative reputation:** Smaller pool, lower quality
- **Neutral (0):** Normal pool size
- **Positive reputation:** Larger pool, higher quality
- **High reputation (>50):** Specialists appear!

### Port Quality

Ports have quality ratings 1-5 (stars):
- ★☆☆☆☆ Small port: 10 crew, basic quality

## 🔧 Engineer Repair System

### Repair Types

1. **Hull Breach** - Critical hull damage (2 hours base)
2. **Flooding** - Water infiltration (1 hour base)
3. **Electrical** - Battery, power systems (45 minutes base)
4. **Mechanical** - Engines, propulsion (1.5 hours base)
5. **Torpedo Tube** - Weapon systems (1.25 hours base)
6. **Sonar** - Sonar equipment (30 minutes base)
7. **Periscope** - Periscope damage (40 minutes base)
8. **Compartment** - General damage (50 minutes base)
9. **Emergency** - Quick combat patches (20 minutes base)

### Repair Speed Calculation

```
Repair Speed = Base Speed
             × Skill Modifier (0.5x to 2.0x)
             × Specialization Modifier (1.0x to 2.5x)
             × Difficulty Modifier (0.5x to 2.0x)
             × Stress Penalty (0.7x to 1.0x)
             × Fatigue Penalty (0.8x to 1.0x)
```

### Specialization Impact

**Example: Hull breach repair**

- **No specialist:** 120 minutes at 70% skill = ~100 minutes
- **Hull Specialist:** 120 minutes at 90% skill + 60% bonus = ~40 minutes!
- **Chief Engineer:** 120 minutes at 85% skill + 50% speed = ~50 minutes

**Specialists make HUGE difference!**

### Auto-Assignment

```python

```

Automatically assigns best engineer for each queued repair based on:
1. Relevant skill level
2. Specialization bonuses
3. Current stress/fatigue
4. Existing workload

## 📋 Usage Examples

### 1. Creating Recruitment Pool

```python
from submarine.crew_recruitment_enhanced import RecruitmentPool

# Create pool at major naval base
pool = RecruitmentPool(port_name="Kiel Naval Base", port_quality=5)

# Refresh pool based on captain level and reputation
captain_level = 10
reputation = 75  # High reputation
pool.refresh_pool(captain_level, reputation)

# View available crew
print(pool.get_summary())

# Filter for engineers
engineers = pool.get_available_crew(skill_filter='engineering')

# Get specialists only
specialists = pool.get_specialists()
```

### 2. Recruiting Crew

```python
# Find veteran engineer
veteran_engineers = pool.get_available_crew(
    quality_filter=CrewQuality.VETERAN,
    skill_filter='engineering'
)

if veteran_engineers:
    crew = veteran_engineers[0]
    
    # View recruitment info
    print(pool.get_recruitment_info(crew))
    
    # Recruit (returns success and cost)
    success, cost = pool.recruit(crew)
    if success:
        print(f"Recruited {crew.name} for {cost} points")
```

### 3. Managing Crew Roster

```python
from submarine.crew_recruitment_enhanced import CrewRosterManager

roster = CrewRosterManager("U-96", max_crew=50)

# Add recruited crew
roster.add_crew(crew)

# Find best engineer
best_engineer = roster.get_best_crew_for_skill('engineering')

# Get all specialists
specialists = roster.get_specialists()

# Get crew in specific compartment
engine_crew = roster.get_crew_by_compartment('engine_room')

# View roster summary
print(roster.get_roster_summary())
```

### 4. Repair System

```python
from submarine.engineer_repairs import EngineerRepairSystem, RepairType

repair_system = EngineerRepairSystem()

# Create repair task
task = repair_system.create_repair(
    repair_type=RepairType.HULL_BREACH,
    severity=0.8,  # 80% damage
    compartment_id='forward_torpedo',
    priority=True  # Emergency!
)

# Get available engineers
engineers = roster.get_crew_by_skill('engineering', min_effectiveness=0.6)

# Auto-assign best engineer
repair_system.auto_assign_engineers(engineers)

# Or manually assign specific engineer
hull_specialist = roster.get_specialists(Specialization.HULL_SPECIALIST)
if hull_specialist:
    repair_system.assign_engineer_to_task(hull_specialist[0], task)

# Perform repair ticks (in game loop)
events = repair_system.tick_all_repairs()
for event in events:
    if event['complete']:
        print(f"Repair complete: {event['message']}")
```

### 5. Crew Development

```python
# Gain experience
crew.gain_xp('engineering', 50)

# Check for specialization eligibility
from submarine.crew_skills import Specialization, SPECIALIZATION_DATA

for spec in Specialization:
    if crew.can_specialize(spec):
        spec_data = SPECIALIZATION_DATA[spec]
        print(f"Can specialize as: {spec.value}")
        print(f"  {spec_data['description']}")

# Specialize crew
if crew.can_specialize(Specialization.CHIEF_ENGINEER):
    crew.specialize(Specialization.CHIEF_ENGINEER)
    print(f"{crew.name} is now a Chief Engineer!")

# View crew details
print(crew.get_description())
```

## 🏆 Strategic Tips

### Early Game (Captain Level 1-4)

- **Recruit diverse skills** - Need coverage of all skills
- **Focus on training** - Turn recruits into trained crew
- **Save for quality** - Wait for trained crew at level 3
- **Avoid specialists** - Can't afford them yet

### Mid Game (Captain Level 5-8)

- **Target experienced crew** - Worth the cost
- **Get first specialists** - Navigator, sonar operator
- **Build reputation** - Better recruitment pools
- **Develop veterans** - Keep good crew alive

### Late Game (Captain Level 9-15)

- **Recruit veterans/aces** - Only the best
- **Full specialist roster** - One of each key role
- **Replace casualties strategically** - Quality over quantity
- **Legendary crew** - Hunt for the best

### Critical Specialists Priority

1. **Chief Engineer** - Repairs win/lose battles
2. **Sonar Operator** - Detection is survival
3. **Weapons Officer** - Better kills
4. **Navigator** - Fuel efficiency & evasion
5. **Damage Controller** - Emergency situations
