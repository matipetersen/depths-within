### 📊 Tileset Specifications

**modern_tileset.png** & **tileset.png**
- Dimensions: 256 x 128 pixels (8×4 grid of 32×32 tiles)
- Format: PNG with RGBA color support
- Color Palette:
  - Navy Blue: `#0A1016` (background)
  - Sonar Green: `#18C878` (active/detection)
  - Amber/Warning: `#FFCC66` (UI/alerts)
  - Steel/Neutral: `#888E96` (structures)
  - Red/Danger: `#C85050` (damage/threat)

### 🎮 Game Integration

**Tileset Loading**
- The game automatically loads `assets/tilesets/atlas.json` for tile definitions
- Falls back to `modern_tileset.png` or `tileset.png` for graphical tileset
- If PNG loading fails, uses tcod's built-in default tileset (game still works)

**Atlas Mapping**
- Format: JSON with tile names mapped to grid indices
- Each tile occupies one 32×32 pixel cell in the tileset
- Grid coordinates automatically calculated from index

**In-Game Usage**
- Tiles are used by `ui/tileset.py` for graphics rendering
- Color approximation available for fallback terminal rendering
- Supports both pixel-perfect rendering (with tcod) and color-block fallback
