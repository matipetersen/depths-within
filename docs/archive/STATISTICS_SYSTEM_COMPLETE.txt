🎮 HOW TO USE IN-GAME

Type any of these commands:

  stats summary      ← Quick overview (most common)
  stats full         ← Complete statistics report
  stats detailed     ← Full report + event logs
  stats combat       ← Combat performance only
  stats crew         ← Crew & personnel only
  stats security     ← Spies & sabotage only
  stats missions     ← Mission completion only
  stats help         ← Show all commands

Or use the hotkey:
  sa                 ← Same as "stats summary"
