USAGE QUICK START
================================================================================

1. System auto-initializes on game start:
   game.rebellion_manager  # RebellionManager instance
   game.war_endgame        # WarEndgameStats instance

2. In-game console commands:
   > crew_loyalty          # Show crew morale summary
   > crew_loyalty_detail 1 # Show crew member details
   > war_status            # Show current war stats
   > end_war               # End game and get final rank

3. Programmatic usage:
   game.rebellion_manager.add_crew_member(1, "John", "brave")
   game.rebellion_manager.apply_crew_event('combat_victory')
   game.war_endgame.enemy_ships_destroyed = 50
   rank = game.war_endgame.calculate_war_rank()
